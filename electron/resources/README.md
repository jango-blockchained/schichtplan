# Electron Resources

This directory should contain the application icons for different platforms:

- `icon.icns` - macOS icon (512x512)
- `icon.ico` - Windows icon (256x256)
- `icon.png` - Linux icon (512x512)

To generate icons, you can use tools like:
- https://www.electronjs.org/docs/latest/tutorial/application-distribution#icon-generation
- https://github.com/electron/asar

For development, placeholder icons are acceptable. For production, use high-quality branded icons.
