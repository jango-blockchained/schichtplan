## How to Use
From the frontend VacationPlanningPage:
```typescript
// User clicks "PDF Export" -> "Jahreskalender"
const url = `${apiBaseUrl}/api/v2/vacation-pdf/yearly-calendar?year=${currentYear}`;
window.open(url, '_blank');
```

The API endpoint:
```
GET /api/v2/vacation-pdf/yearly-calendar?year=2024
```

Returns a PDF with:
- DIN A4 Landscape format
- 2 pages (6 months each)
- 2x3 grid layout per page
- Bullet points (•) on dates with approved absences
- Legend showing total approved requests
- Store name in title (if available)
