MCP Service FastMCP 2.5.0 Compatibility Fix
============================================

PROBLEM STATEMENT
-----------------
The test_mcp_comprehensive.py script reported multiple failures:
1. AttributeError: 'FastMCP' object has no attribute '_tools'
2. 500 Server errors on /api/v2/mcp/test-tool endpoint
3. Tool execution failures for manage_employees, analyze_workload, validate_coverage

ROOT CAUSE
----------
FastMCP library version 2.5.0 changed its internal API and no longer exposes
_tools, _resources, and _prompts as accessible dictionary attributes. The 
codebase was attempting to directly access these private attributes.

SOLUTION IMPLEMENTED
--------------------

1. SchichtplanMCPService (src/backend/services/mcp_service.py):
   - Added tracking dictionaries: _registered_tools, _registered_resources, _registered_prompts
   - Updated _register_tools() to collect tool metadata during registration
   - Updated _register_prompts() to track prompt metadata
   - Updated _register_resources() to track resource metadata
   - Added public accessor methods: get_registered_tools(), get_registered_resources(), get_registered_prompts()
   - Added get_mcp_server() to return FastMCP instance

2. MCP Routes (src/backend/routes/mcp_routes.py):
   - Updated list_mcp_resources() to use get_registered_resources()
   - Updated list_mcp_prompts() to use get_registered_prompts()
   - Updated test_mcp_tool() to return validation info instead of executing
   - Updated execute_mcp_tool() to provide guidance on proper MCP usage

3. Test Coverage (tests/backend/test_mcp_routes.py):
   - Added comprehensive test suite for all MCP endpoints
   - Tests health, config, tools, resources, prompts endpoints
   - Tests tool validation and execution info endpoints

VERIFICATION
------------
All code has been verified to:
- No longer access private FastMCP attributes (_tools, _resources, _prompts)
- Use public accessor methods from SchichtplanMCPService
- Properly track metadata during component registration
- Return appropriate responses for all endpoints
