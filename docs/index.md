## What is Schichtplan?

**Schichtplan** is a next-generation employee scheduling system that combines modern web technologies with artificial intelligence to revolutionize workforce management. Whether you're managing a small retail store or a large healthcare facility, Schichtplan provides the tools you need to create optimal schedules efficiently.

### Key Highlights

- **🤖 AI-Powered**: Built-in AI integration for schedule optimization and natural language interactions
- **🔐 Secure**: Passwordless authentication using WebAuthn/Passkeys with biometric support
- **🚀 Multi-Platform**: Web, Docker, Desktop (Windows/macOS/Linux), and Telegram bot
- **📊 Intelligent**: Automated shift assignment based on coverage needs, preferences, and compliance
- **🎨 Modern UI**: Beautiful, responsive interface built with React and Shadcn UI
- **🔧 Developer-Friendly**: Comprehensive REST API and extensive documentation
- **📱 Mobile-Ready**: Responsive design and Telegram bot for on-the-go management
- **🌍 Self-Hosted**: Full control over your data—run it anywhere you want

## Why Choose Schichtplan?

### For Managers

- **Save Time**: Automated schedule generation based on your rules and constraints
- **Reduce Conflicts**: AI-powered conflict detection and resolution
- **Ensure Coverage**: Visual coverage indicators and intelligent staffing recommendations
- **Stay Compliant**: Built-in labor law and contract hour tracking
- **Easy Sharing**: Export to PDF or share via Telegram

### For Developers

- **Modern Stack**: React, TypeScript, Flask, SQLAlchemy—battle-tested technologies
- **Clean Architecture**: Well-organized codebase with comprehensive tests
- **Extensive API**: RESTful API with OpenAPI documentation
- **AI Integration**: MCP server for seamless AI tool integration
- **Active Development**: Regular updates and responsive maintainers

### For Organizations

- **Self-Hosted**: Complete data sovereignty—your data stays with you
- **Cost-Effective**: Open-source with no per-user fees
- **Scalable**: From small teams to large organizations
- **Customizable**: Extensive configuration options and extensible architecture
- **Well-Documented**: Comprehensive guides and documentation

## Use Cases

Schichtplan is perfect for:

- 🏪 **Retail Stores**: Complex shift patterns, keyholder requirements, part-time/full-time mix
- 🏥 **Healthcare**: 24/7 coverage, compliance requirements, skill-based scheduling
- 🍽️ **Restaurants**: Peak hour staffing, varying demand patterns, employee preferences
- 🏢 **Corporate**: Office shifts, flexible working hours, remote/on-site coordination
- 🏭 **Manufacturing**: Multi-shift operations, coverage optimization, skill matching
