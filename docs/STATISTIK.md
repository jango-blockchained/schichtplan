# Benötigte Daten

## Daten für die Analyse der Generierung

- Total Weekly Hours (coverage, over/under )
- Coverage Analysis:
  - Total weekly hours per employee (actual vs. target)
  - Coverage gaps (times with insufficient staff)
  - Overstaffing periods (times with excess staff)
  - Distribution of shift types (Early/Middle/Late) per employee
  - Keyholder coverage per shift

- Employee Workload:
  - Average hours per employee
  - Maximum/minimum hours per employee
  - Consecutive working days
  - Weekend shifts distribution
  - Overtime hours (above target weekly hours)

- Shift Distribution:
  - Shift type distribution (Early/Middle/Late ratio)
  - Preferred vs. assigned shifts
  - Fixed availability fulfillment rate
  - Weekend vs. weekday distribution
  - Keyholder shift distribution

- Quality Metrics:
  - Employee preference satisfaction rate
  - Coverage requirement fulfillment rate
  - Constraint violation count
  - Version comparison metrics (if multiple versions exist)
  - Historical pattern alignment
